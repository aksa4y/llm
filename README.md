# Русский локальный помощник

Основной режим теперь использует готовую **Qwen3-1.7B** от Qwen:
https://huggingface.co/Qwen/Qwen3-1.7B (лицензия Apache-2.0).
Это обученная многоязычная диалоговая модель, понимающая русский язык.
Собственное обучение и датасет GuppyLM для этого режима не нужны.

## Windows

Установите Python 3.10+ и запустите **run.bat**.
Скрипт создаст отдельное окружение, установит зависимости, скачает официальные
веса в `models/qwen3-1.7b` и запустит чат. Первый запуск требует интернета
и загрузки нескольких гигабайт. Веса не хранятся в GitHub.
Повторные запуски переиспользуют скачанные файлы.

Для полностью автономного запуска после загрузки:

```bat
.venv-chat\Scripts\python.exe russian_chat.py --offline
```

## Linux / ручной запуск

```bash
python -m venv .venv-chat
source .venv-chat/bin/activate
python -m pip install -r requirements-chat.txt
python russian_chat.py
# Только скачать веса:
python russian_chat.py --download-only
# Проверочный вопрос:
python russian_chat.py --offline --prompt "Почему меняются времена года?"
```

`/clear` очищает историю, `/exit` завершает чат. По умолчанию сохраняются
последние шесть обменов сообщениями; история не записывается на диск.
Контекст ограничен 4096 токенами для умеренного расхода памяти.

CPU поддерживается, но работает медленнее. Для CPU желательно около 16 ГБ ОЗУ:
одни веса в используемом режиме float32 занимают приблизительно 8 ГБ.
На CUDA веса загружаются в float16 (около 4 ГБ без учёта контекста и накладных расходов).
Для экономии памяти на CPU можно попробовать `--precision bfloat16`:
поддержка и скорость зависят от процессора. Для NVIDIA нужна сборка PyTorch с поддержкой CUDA; проверьте `torch.cuda.is_available()`.
Автоматический выбор использует CUDA, если она доступна, иначе CPU.

Ответы направляются на русский системной инструкцией; при обнаружении
преимущественно иностранного текста выполняется повторная генерация.
Имена, ссылки и код допускаются в оригинале. Эвристика языка не даёт абсолютной
гарантии, а маленькая модель может ошибаться в фактах и сложных задачах.
Режим рассуждений включён для повышения точности; в чате отображается только итоговый ответ.
На CPU подготовка ответа может занимать заметное время.
`--max-tokens` ограничивает общий объём генерации, включая скрытые рассуждения;
слишком маленький лимит может не оставить места итоговому ответу.

## Экспериментальная GuppyLM

Прежний код и корпус оставлены отдельно для экспериментов.
`train_ru.bat` и `chat_ru.bat` относятся только к маленькой GuppyLM.
Новые веса Qwen с этой архитектурой несовместимы; используйте `run.bat`.

# GuppyLM-RU

Русская адаптация [arman-bd/guppylm](https://github.com/arman-bd/guppylm).

Небольшая экспериментальная модель с характером аквариумной рыбки.
Это **код и синтетический датасет, а не готовые обученные русские веса**.
Модель не является универсальным помощником и не заменяет большие языковые модели.

## Запуск

Python 3.10+; установите зависимости в отдельное виртуальное окружение:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python -m guppylm prepare
python -m guppylm train --device auto --max-steps 10000
python -m guppylm chat --checkpoint checkpoints/final_model.pt
```

На Windows можно запустить `train_ru.bat`, затем `chat_ru.bat`.
Обучение выполняется с нуля: новый токенизатор несовместим с исходными весами.
Команда download заблокирована, чтобы случайно не подменить русский токенизатор английским.
Видеопамять и время обучения зависят от устройства. CUDA используется при наличии подходящей сборки PyTorch.

## Датасет

`datasets/ru/train.jsonl`, `eval.jsonl`, `manifest.json` — версия корпуса в Git.
`python -m guppylm.russian_data --data-dir datasets/ru` воспроизводит его.
`prepare` создаёт рабочую копию в data и обучает BPE только на train.
Корпус содержит авторские короткие диалоги, бытовую русскую лексику,
сцены аквариума и примеры сохранения русского языка при иностранных запросах.
Лицензия новых синтетических данных: CC0-1.0. Шаблонные семейства train/eval не пересекаются.
Это небольшой стартовый корпус: для качественного свободного общения нужен существенно
более разнообразный проверенный корпус, отдельный тестовый набор и длительное обучение.
Не следует считать множество вариаций шаблонов независимыми знаниями.

## Только русский язык

В обучении и инференсе используется одинаковое системное сообщение.
На выходе проверяются буквы: допускаются русские буквы, цифры и знаки препинания.
Пустой ответ или ответ с иностранными буквами заменяется русской фразой.
Это строгая политика интерфейса: латинские ссылки, названия и код тоже отклоняются.
Проверка алфавита не гарантирует осмысленность ответа или качество знания русского языка.
