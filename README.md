# GuppyLM-RU

Русская адаптация [arman-bd/guppylm](https://github.com/arman-bd/guppylm).

Небольшая экспериментальная модель с характером аквариумной рыбки.
Это **код и синтетический датасет, а не готовые обученные русские веса**.
Модель не является универсальным помощником и не заменяет большие языковые модели.

## Запуск

Python 3.10+; установите зависимости в отдельное виртуальное окружение:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python -m guppylm prepare
python -m guppylm train --device auto --max-steps 10000
python -m guppylm chat --checkpoint checkpoints/final_model.pt
```

На Windows можно запустить `train_ru.bat`, затем `chat_ru.bat`.
Обучение выполняется с нуля: новый токенизатор несовместим с исходными весами.
Команда download заблокирована, чтобы случайно не подменить русский токенизатор английским.
Видеопамять и время обучения зависят от устройства. CUDA используется при наличии подходящей сборки PyTorch.

## Датасет

`datasets/ru/train.jsonl`, `eval.jsonl`, `manifest.json` — версия корпуса в Git.
`python -m guppylm.russian_data --data-dir datasets/ru` воспроизводит его.
`prepare` создаёт рабочую копию в data и обучает BPE только на train.
Корпус содержит авторские короткие диалоги, бытовую русскую лексику,
сцены аквариума и примеры сохранения русского языка при иностранных запросах.
Лицензия новых синтетических данных: CC0-1.0. Шаблонные семейства train/eval не пересекаются.
Это небольшой стартовый корпус: для качественного свободного общения нужен существенно
более разнообразный проверенный корпус, отдельный тестовый набор и длительное обучение.
Не следует считать множество вариаций шаблонов независимыми знаниями.

## Только русский язык

В обучении и инференсе используется одинаковое системное сообщение.
На выходе проверяются буквы: допускаются русские буквы, цифры и знаки препинания.
Пустой ответ или ответ с иностранными буквами заменяется русской фразой.
Это строгая политика интерфейса: латинские ссылки, названия и код тоже отклоняются.
Проверка алфавита не гарантирует осмысленность ответа или качество знания русского языка.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Исходные notebooks и экспортные tools сохранены как материалы upstream;
они не адаптированы под русский корпус. Для русской версии используйте CLI выше.
