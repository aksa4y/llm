# Русский локальный помощник — Qwen3 4B

Основная модель: **Qwen3-4B-Instruct-2507**, готовая диалоговая модель Qwen
на 4 млрд параметров. Используется GGUF Q4_K_M от Unsloth (около **2.5 ГБ**).
Модель: https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507
Веса: https://huggingface.co/unsloth/Qwen3-4B-Instruct-2507-GGUF
Лицензия модели и конверсии: Apache-2.0. Источник и ревизия закреплены в коде.

## Windows

Установите **64-битный Python 3.12** с python.org, включив Add Python to PATH,
и запустите **run.bat**. Скрипт создаст окружение, установит готовую сборку
llama.cpp для CPU, скачает веса и откроет чат. Visual Studio и PyTorch не нужны.
Первый запуск требует интернета и около 2.5 ГБ загрузки модели.
Веса сохраняются в `models/qwen3-4b`; они не включены в GitHub.
После загрузки можно работать полностью без интернета:

```bat
.venv-chat\Scripts\python.exe russian_chat.py --offline
```

Если осталась среда от ранней версии с Qwen 1.7B/PyTorch, её можно удалить
и заново запустить run.bat: для нового чата она не требуется.

## Linux / ручной запуск

```bash
python3.12 -m venv .venv-chat
source .venv-chat/bin/activate
python -m pip install --only-binary=:all: --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu -r requirements-chat.txt
python russian_chat.py
python russian_chat.py --download-only
python russian_chat.py --offline --prompt "Почему меняются времена года?"
```

Если для вашей версии Python/ОС нет готовой сборки, используйте Python 3.12
x64. Скрипт намеренно не пытается собирать C++ библиотеку самостоятельно.

## Возможности и требования

Ответы на русском, история последних шести обменов сообщениями,
`/clear` для очистки и `/exit` для выхода. Диалог не сохраняется на диск.
Контекст ограничен 4096 токенами для умеренного расхода памяти.
Для начала желательно 8 ГБ ОЗУ, комфортнее 16 ГБ. Работа на CPU зависит от
процессора; сжатые веса требуют значительно меньше памяти, чем исходные.

Запуск по умолчанию использует CPU. Для ускорения на NVIDIA нужна отдельно
установленная CUDA-сборка llama-cpp-python; затем используйте
`python russian_chat.py --offline --gpu-layers -1`. Стандартный run.bat
устанавливает CPU-сборку. Инструкции сборок:
https://github.com/abetlen/llama-cpp-python#installation

Русский язык задаётся системной инструкцией и проверкой ответа с одной
повторной попыткой. Код, ссылки и латинские названия допускаются в оригинале.
Эвристика языка не гарантирует абсолютной чистоты языка. Модель может ошибаться
в фактах; это компактный локальный помощник, а не замена больших моделей.
Эта версия Instruct отвечает напрямую, без скрытого режима рассуждений.

## Экспериментальная GuppyLM

Прежний код и корпус оставлены отдельно для экспериментов.
`train_ru.bat` и `chat_ru.bat` относятся только к маленькой GuppyLM.
Веса Qwen с этой архитектурой несовместимы; для готового помощника используйте run.bat.

# GuppyLM-RU

Русская адаптация [arman-bd/guppylm](https://github.com/arman-bd/guppylm).

Небольшая экспериментальная модель с характером аквариумной рыбки.
Это **код и синтетический датасет, а не готовые обученные русские веса**.
Модель не является универсальным помощником и не заменяет большие языковые модели.

## Запуск

Python 3.10+; установите зависимости в отдельное виртуальное окружение:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python -m guppylm prepare
python -m guppylm train --device auto --max-steps 10000
python -m guppylm chat --checkpoint checkpoints/final_model.pt
```

На Windows можно запустить `train_ru.bat`, затем `chat_ru.bat`.
Обучение выполняется с нуля: новый токенизатор несовместим с исходными весами.
Команда download заблокирована, чтобы случайно не подменить русский токенизатор английским.
Видеопамять и время обучения зависят от устройства. CUDA используется при наличии подходящей сборки PyTorch.

## Датасет

`datasets/ru/train.jsonl`, `eval.jsonl`, `manifest.json` — версия корпуса в Git.
`python -m guppylm.russian_data --data-dir datasets/ru` воспроизводит его.
`prepare` создаёт рабочую копию в data и обучает BPE только на train.
Корпус содержит авторские короткие диалоги, бытовую русскую лексику,
сцены аквариума и примеры сохранения русского языка при иностранных запросах.
Лицензия новых синтетических данных: CC0-1.0. Шаблонные семейства train/eval не пересекаются.
Это небольшой стартовый корпус: для качественного свободного общения нужен существенно
более разнообразный проверенный корпус, отдельный тестовый набор и длительное обучение.
Не следует считать множество вариаций шаблонов независимыми знаниями.

## Только русский язык

В обучении и инференсе используется одинаковое системное сообщение.
На выходе проверяются буквы: допускаются русские буквы, цифры и знаки препинания.
Пустой ответ или ответ с иностранными буквами заменяется русской фразой.
Это строгая политика интерфейса: латинские ссылки, названия и код тоже отклоняются.
Проверка алфавита не гарантирует осмысленность ответа или качество знания русского языка.
